# 第一卷第 9 章：网络爬虫

## 学习目标与原文对齐

对应 URL Frontier、下载、解析、URL/内容去重、礼貌性、鲁棒性和陷阱。目标：能解释调度与去重如何共同决定抓取效率。先修 V1-01、04；关联 V2-04。

## P0 交互一：爬取一个虚构小网络

- 初始：3 个域名、12 个虚构页面；包含环 A→B→A、两个 URL 相同内容、一个禁止抓取路径和一个失效页。
- 画面：页面链接图与 Seed→Frontier→下载→解析→去重→存储→新 URL 的流水线，队列可展开。
- 操作：选择种子，单步抓取，切换 URL 去重与内容去重；点击页面查看发现来源和抓取结果。
- 反馈：分别计数发现 URL、唯一 URL、下载次数、唯一内容。相同内容的不同 URL 可能仍需下载才能判定，不把内容去重误画成总能提前避免请求。
- 样例：关闭 URL 去重后环不断生成待处理项；打开后 A/B 各处理一次。对内容重复页保留别名关联，不重复保存正文。

## P1 交互二：礼貌调度与故障重试

- 参数：每域间隔 1—10 模拟秒、工作者 1—6、超时 1—5 秒、重试上限 0—3 次。
- 操作：向同一域注入 10 个 URL，同时另一域有 2 个；对比简单全局 FIFO 与每域队列调度；使一个下载一直超时。
- 反馈：时间轴显示同一域相邻请求间隔，空闲工作者可处理其他域；重试有退避和上限，不挤占全部正常任务。
- 进阶：给无限日历链接设置深度/参数规则和抓取预算，展示停止原因；所有页面与 robots 规则为内置数据，不执行真实爬取。

## 思维导图

- 目标 → 覆盖率、新鲜度、预算、礼貌性。
- 发现 → 种子、链接提取、过滤、URL 去重。
- 调度 → Frontier、优先级、每域队列、间隔。
- 处理 → DNS、下载、解析、内容去重、存储。
- 鲁棒性 → 超时、退避、检查点、陷阱与预算。

## 额外学习内容与练习

增加流水线职责拼图、URL 去重与内容去重的双集合图。P2 提供“在 20 次下载预算内最大化覆盖”的挑战。

1. 预测题：A→B→A 开启 URL 去重后是否无限抓取？答案：不会。
2. 排序题：内容去重一般在哪一步有足够信息？要点：下载并得到可比较内容之后。
3. 诊断题：增加工作者为何同一域吞吐不增加？要点：礼貌间隔限制。
4. 取舍题：更频繁重抓与发现新页面如何分配预算？要点：依据更新频率与目标。

## 验收与边界

同域间隔可人工核验；死循环和重试有预算；统计口径不同不能混加；URL 规范化误合并不同页面的风险单列说明；可恢复到检查点并看到剩余任务。
