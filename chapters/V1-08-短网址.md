# 第一卷第 8 章：短网址

## 学习目标与原文对齐

对应 API、重定向、数据模型、哈希、Base62、创建与读取路径。目标：区分编码与哈希，解释冲突、缓存和统计对设计的影响。先修 V1-01、02、07。

## P0 交互一：从长链接创建短码

- 画面：客户端、创建服务、ID 生成器、映射表；旁边为每次操作的输入与输出。
- 操作：输入虚构长链接，切换“唯一 ID 后 Base62 编码”和“截断哈希后检查冲突”；查看字符如何组成短码。
- 参数：示意短码长度 2—7、是否重复长链接复用、是否自定义别名。Base62 字符顺序明确固定。
- 样例：人为设置两条不同链接得到同一截断结果 ab；第一次插入成功，第二次触发冲突分支并生成另一个候选，不能覆盖旧记录。
- 反馈：显示候选次数、映射表变化、编码容量 62^L；强调容量上限不等于随机哈希在用满前不会碰撞。

## P1 交互二：一次点击去了哪里

- 画面：浏览器缓存、重定向服务、缓存、数据库和统计队列，区分创建和访问两条路径。
- 操作：首次点击、重复点击、清服务端缓存、修改目标地址；对比 301/302 的教学预设。
- 规则：为演示明确配置“301 在浏览器保留缓存，302 不存储”；同时说明真实缓存还受响应头和客户端行为影响，不能只由状态码推断。
- 样例：首次请求服务，第二次浏览器直接使用缓存；服务端点击日志只有一次，但浏览器导航有两次。关闭浏览器缓存后再次对照。
- 异常：未知短码、过期短码、热点短码缓存失效；展示错误响应或回源，进阶加并发回源保护。

## 思维导图

- 需求与规模 → 创建/访问比、有效期、可修改性、统计。
- 生成 → 唯一 ID、Base62、截断哈希、冲突检测。
- 数据 → 短码到目标、唯一约束、过期。
- 跳转 → 301/302、浏览器缓存、服务端缓存、回源。
- 扩展 → 热点、分片、分析链路、失效策略。

## 额外学习内容与练习

增加创建/读取的双时序图、短码容量计算卡、选型辩论卡“为何不总用同一种跳转”。

1. 预测题：两条不同链接短码相同时能直接覆盖吗？答案：不能，需冲突处理或拒绝。
2. 排序题：缓存未命中访问路径如何走？要点：查映射、按策略回填、返回跳转。
3. 诊断题：真实导航次数大于服务端统计数为什么？要点：浏览器/中间缓存等可绕过服务。
4. 取舍题：链接目标可修改时怎么设计缓存？要点：考虑失效与有效期，不把永久缓存当默认。

## 验收与边界

能复现冲突且旧链接不被覆盖；样例不访问真实目标；状态码缓存假设明确；请求追踪中区分导航次数与服务端请求次数；Base62 编码不被讲成加密。
