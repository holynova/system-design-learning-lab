# 第一卷第 5 章：一致性哈希

## 学习目标与原文对齐

对应再哈希、哈希环、查找、增删服务器、分区不均和虚拟节点。目标：能手动定位键，解释节点变更造成的迁移范围，以及负载不均的两种来源。先修 V1-01。

## P0 交互一：可操作的哈希环

- 画面：0—99 的环，节点 A=20、B=50、C=80；键位置列表与所有权表。规则固定为顺时针遇到的第一个节点，恰好重合归该节点。
- 操作：点击键追踪查找路径，增加 D=35，删除一个节点；切换到 hash(key) mod N 的对照表。
- 样例：键 10/25/40/70/90 初始归 A/B/B/C/A；加 D=35 后只有键 25 从 B 迁到 D。高亮区间 (20,35]，而非整段 B 的原区间。
- 参数：实体节点 2—8、键 5—200；允许拖节点或输入位置。固定初始数据，避免比较时键重新随机。
- 反馈：列出迁移键、前后目标、迁移比例、各节点键数；区分“映射变化”与现实中的数据拷贝过程。

## P1 交互二：虚拟节点与热点键

- 操作：每个实体节点虚拟节点数切换 1/4/16；使用同一批键比较分布；再把一个键的请求频率提高到其他键的 100 倍。
- 反馈：同时展示存储键数和请求量柱图。虚拟节点可能改善键分布，但单个热点键仍集中；提示需要另行讨论缓存、拆分或复制。
- 异常：删除实体节点时同时删除其所有虚拟节点；查看迁移分散到哪些实体节点。恢复时标明重新映射与数据回填。
- 讲解限制：小样本不保证每次增加虚拟节点都降低方差；仅展示该样本结果，支持多个固定种子复测。

## 思维导图

- 问题 → 取模变化、大量重映射、缓存失效。
- 环上规则 → 哈希空间、节点位置、键位置、顺时针后继。
- 成员变化 → 新增、移除、受影响区间、迁移。
- 虚拟节点 → 实体映射、分布均衡、元数据开销。
- 边界 → 热点键、节点容量、复制与分片区别。

“受影响区间”链接主实验；“数据复制”跳 V1-06，避免把两种机制混淆。

## 额外学习内容与练习

增加“预测归属”小游戏、迁移前后差异图和从缓存到存储路由的应用卡。

1. 预测题：加入 D=35 后键 25 和 40 分别到哪？答案：D、B。
2. 操作题：删除 C 时先圈出受影响区间再执行。要点：原来归 C 的键交给后继。
3. 诊断题：键数均衡但某台 CPU 很高，为什么？要点：访问热度或单键成本不同。
4. 取舍题：虚拟节点越多越好吗？要点：均衡收益与管理开销、实际规模相关。

## 验收与边界

处理环首尾和重合位置；不允许静默产生重复节点位置；实体节点删除逻辑正确；迁移统计基于实际键集，不宣称固定百分比。复制、故障检测不被冒充为一致性哈希自带能力。
